# Node.js 22, 24 and 26 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The published packages support exactly the Node LTS lines 22, 24 and 26, and CI proves it on all three.

**Architecture:** Configuration only: Vitest configs, `package.json` files (engines, `@types/node`), the lockfile, GitHub workflows, `.nvmrc`, one changeset and three docs. No API change.

**Tech Stack:** pnpm 10 workspaces, Vitest 4 (`InlineConfig.execArgv`), changesets (sdk/react linked), GitHub Actions (`actions/setup-node@v7`).

**Spec:** `docs/superpowers/specs/2026-11-23-node-lts-22-24-26-design.md`

## Global Constraints

- Engines range, verbatim, in all five packages and the root: `"^22.12.0 || ^24.0.0 || >=26.0.0"`. The Angular package uses the same range, not Angular's.
- Bumps: `@viu/emporix-sdk` major, `@viu/emporix-sdk-react` major, `@viu/emporix-sdk-angular` **minor** (0.7.0 → 0.8.0), `@viu/emporix-sdk-next` major, `@viu/emporix-mixins` major.
- Node flag for jsdom suites: `--no-experimental-webstorage` (never `--no-webstorage`: Node 24 rejects it).
- `@types/node`: `^22.0.0` in the five packages. Examples are not touched.
- `.nvmrc`: `26`. Single-version workflows use `node-version-file: .nvmrc`.
- No API change, no deprecation removed, TypeScript `target`/`lib` stay `ES2022`.
- Local Node binaries: 22 = `~/.nvm/versions/node/v22.16.0/bin`, 24 = `~/.nvm/versions/node/v24.11.1/bin`, 26 = `/opt/homebrew/opt/node@26/bin`. Put the chosen one first on `PATH`; pnpm lives in the 22 and 24 bins and under `/opt/homebrew/bin`.
- Commits: commitlint conventional types, scopes from `commitlint.config.js`, lowercase verb first, body lines ≤ 100 chars, no `#N` in body lines. Everything committed is English.

## Review Focus

1. **Angular 20/21 users on Node 22.12–22.22** must not get an engines warning from `@viu/emporix-sdk-angular`. Pinned by the engines-equality check in Task 3.
2. **Users on the odd lines 23 or 25** get a warning by design. The changeset must say so, so the warning is not a surprise. Pinned by the changeset check in Task 3.
3. **A CI row that silently skips steps** (the anti-goal). Pinned by the workflow check in Task 4.
4. **The release job on Node 26** must still publish through npm Trusted Publishing, which needs npm ≥ 11.5.1. Pinned by the npm-version check in Task 4. The real proof is the next release run, which nobody can trigger from this PR.
